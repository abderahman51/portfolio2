# Abdelrahman Sabry — Portfolio

نسخة جديدة جاهزة للرفع على GitHub Pages، بتصميم Editorial Warm Tech بألوان فحمي وعاجي وبرتقالي محروق وزيتي، مع الفيديوهات المضغوطة وكارت تسجيل الشاشة الجديد.

## شكل الملفات بعد فك الضغط

```text
index.html
css/
js/
assets/
cv/
manus-routes.json
.nojekyll
```

## الرفع على GitHub

1. فك الضغط عن الملف.
2. افتح الريبو على GitHub.
3. ارفع **كل محتويات الحزمة** إلى جذر الريبو، وليس مجلدًا اسمه `portfolio`.
4. تأكد أن `index.html` ظاهر مباشرة بجوار `README.md`.
5. من `Settings → Pages` اختر `Deploy from a branch` ثم `main` ثم `/(root)` واضغط `Save`.
6. انتظر دقيقة أو دقيقتين ثم افتح رابط GitHub Pages.

## الفيديوهات الموجودة

كل الفيديوهات داخل `assets/videos/` ومضغوطة لتناسب الرفع من متصفح GitHub:

- `morshedy.mp4`
- `world-cup.mp4`
- `soly-vie-landing.mp4`
- `soly-vie-dashboard.mp4`
- `screen-recording.mp4`

تمت إضافة `screen-recording.mp4` إلى الموقع ككارت مستقل باسم **Project Walkthrough — Screen Recording**.

## رابط الموقع المتوقع

```text
https://<username>.github.io/<repository-name>/
```

إذا لم يظهر التصميم، فغالبًا تم رفع الملفات داخل مجلد إضافي أو تم اختيار `/docs` بدل `/(root)` في إعدادات Pages.
